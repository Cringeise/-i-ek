# Gece Bahçesi

Karanlık gökyüzü altında animasyonlu çiçeklerden oluşan küçük bir buket deneyimi.

## Çalıştırma

`index.html` dosyasını güncel bir tarayıcıda açman yeterli. Harici paket veya derleme adımı gerekmez.

## Dosyalar

- `index.html`: Sayfa yapısı ve çiçek SVG çizimleri.
- `style.css`: Gece görünümü, buket düzeni ve çiçek açılma/salınım animasyonları.
- `script.js`: 22 çiçeklik buket yerleşimi, gökyüzü efektleri ve Sevgi Barı oyunu.

Sevgi Barı rekoru yalnızca ziyaretçinin kendi tarayıcısında `localStorage` ile saklanır.
